Administrator configuration required

Admin access is configured by the application owner.

There is no public admin registration. The application owner sets the admin username and password in the server environment before staff can sign in.

For the application owner

Set ADMIN_USERNAME, ADMIN_PASSWORD, and a private ADMIN_SESSION_SECRET on the server. Never add these values to frontend code or public environment variables.

Share the admin credentials only with authorized staff.
